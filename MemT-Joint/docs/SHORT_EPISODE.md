# 空状态短 episode 训练与速度验收

本轮仅改变训练粒度及独立分支的执行批次。每个 episode 从空状态开始，按原顺序处理最多 8 个原始 block（每块最多 4 turn）；不加载旧 prefix 快照。B/U/R 共享权重，4 Global、4 Local-B、4 Local-U、一个 anchor、每组 4 QA 和现有损失、KL、优势、长度归一化及分支权重保持不变。

训练数据仅来自原 train 的 conv-26，111 block 划为 14 个连续 clip（末段 7 块）。人工编写方式为本聊天助手对照原文编写并审查，共 112 个 QA，每个 clip 8 个；并非独立人工标注或另一模型盲审。逐题保存引用 turn、原句、短答案、窗口末时间与源文件哈希，程序确认答案短语来自引用、证据在 clip 内并跨越至少两个 block。未读取 valid/test 生成训练 QA。QA 答案和证据只供评分，不进入 B/U/R prompt。

Global 在窗口末评分。Local anchor 从同时包含新写入及旧事实 QA、且存在 U 候选的 block 中，按固定随机种子选取；B/U 各候选及不执行当前 U 的基准都继续贪心回放至同一窗口末，最多再处理 7 块。每个 branch 内 U 顺序不变，不同 branch 间批处理。R 的 MoT 在一个固定状态上比较路径；每步使用该 clip 的 8 个不同 QA（原 32 是上限），不复制 QA 凑数，角色与分支权重总量不变。

验收先运行独立两步真实共享 RL，分别覆盖冷/已有 Adam 状态。普通训练计算使用 wall_seconds，包含采样、当前 policy 答案、评分、old/ref、反向、Adam 和权重切换；每步必须 ≤1800 秒，Global/Local 样本和 B/U/R 权重必须完整，才生成计算口径的 PROFILE_PASSED。周期保存/日志和完整 81 题验证分别单列。原始 ordinary_step_seconds_including_checkpoint 保留，receipt 额外报告 full_step_including_checkpoint_passed，不能用计算通过冒充含保存总耗时通过。

首轮两卡实测计算为 1201.61 / 1506.49 秒，含保存及日志为 1206.39 / 1814.85 秒；严格含保存验收未通过（第二步超约 15 秒），其 253954 FAILED 回执保留，依赖正式作业 253955 被取消，未执行训练。检查点约 23.2 GiB。后续仅变更验收计时边界和运行 STOP 路径的配置比较，不改采样/训练/保存实现；新正式 run 通过相同计算源码哈希绑定这两步证据。普通计算已达标，不声称已优化保存 I/O，也不承诺所有 50 步均小于 30 分钟。

正式 50 步必须使用同一已验收源码、数据、基础模型及推理协议，并重新从基础权重初始化；不继承测速更新。正式 step0 从空库重新构建完整 valid 对话，每 10 步再次执行完整 81 题验证。仍使用 paper-v2、Chroma/BGE-M3、Mem-T 原始提示词/工具/观察、当前检索 policy 的 finish(answer)、40K 预算，不加载冻结 Answer。保留 latest 完整恢复检查点和 best 模型。短 QA 更偏局部可回答事实，速度通过不能证明完整长程记忆质量，需看完整 valid 轨迹。
